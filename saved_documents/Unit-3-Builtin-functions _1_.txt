Cont..  •   When   you   include   a   group   function   and   the   GROUP   BY   clause  in   your   query,   the   individual   column(s)   appearing   in   SELECT  must   also   appear   in   GROUP   BY .  •   The   WHERE   clause   can   still   be   used   to   restrict   data   before  grouping.  •   The   WHERE   clause   cannot   be   used   to   restrict   groups.  •   A   column   alias   cannot   be   used   in   a   GROUP   BY   clause.  •   The   GROUP   BY   column   does   not   have   to   appear   in   a   SELECT  query

Examples  Average salary by department:  SELECT   DepartmentId , AVG(Salary) FROM employee GROUP BY   DepartmentId ;  •   Employees are divided into groups based on   DepartmentId , and the average salary is  calculated for each department. Summary  32  Built - in functions enhance basic SQL queries.  Single - row functions return one result for each row.  Character, numeric and date functions support manipulation and calculation.  Conversion functions provide explicit type conversion.  NVL - family functions handle NULL values.  DECODE and CASE implement conditional logic.  Group functions summarize data across multiple rows.  DUAL is useful for testing expressions and functions.
